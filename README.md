## 🎯 What it does
Aurora UI is a high-performance landing page design system engineered specifically for developers, AI platform builders, and technical consultants. It features an interactive scope & budget estimator, accessible components, and zero client-side library dependencies.

### Key Capabilities:
1. **Sub-100ms Page Load**: Pure HTML5 and vanilla CSS variables with zero bloated JavaScript frameworks.
2. **Interactive Cost & Scope Calculator**: Real-time project price synthesizer based on timeline and requirements.
3. **Responsive Dark Mode UI**: Engineered with modern typography, contrast compliance, and CSS grid layout.
4. **Zero-Setup Deployment**: Can be served statically on GitHub Pages, Vercel, Netlify, or standard Nginx/Apache.

---

## 🛠️ Architecture & Tech Stack
- **HTML5**: Semantic tags, accessibility (a11y) landmarks, OpenGraph tags
- **CSS3**: Custom design tokens, CSS Grid, Flexbox, hardware-accelerated transitions
- **Vanilla JavaScript**: Pure DOM calculations (zero npm packages required)

## 🚀 Getting Started
Open `index.html` in any browser or run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
